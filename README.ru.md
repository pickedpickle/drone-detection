# Пост детекции дронов

[English](README.md) | **Русский**

Стационарный **пост раннего обнаружения дронов** — точка наблюдения, которая детектирует воздушные дроны (квадрокоптеры, самолётного типа — Shahed/Герань) по RTSP-потоку с камеры и подаёт аппаратный алёрт. **Defensive: только детекция и оповещение, без противодействия.**

Личный некоммерческий исследовательский проект. Автор — самоучка. В разработке.

## Зачем
Поймать дрон на пределе видимости, где он занимает несколько пикселей. Приоритет — **recall** (полнота): лучше ложная тревога, чем пропущенный дрон. Весь пайплайн заточен под дальнюю детекцию на телеобъективах (imgsz=1280 — дальняя цель получает вчетверо больше пикселей, чем на 640).

## Что здесь
Утилиты вокруг пайплайна детекции (сам живой детектор — `GRIDEN` — добавляется в отдельный репо):

- **`compare_models.py`** — две модели YOLO бок о бок на живом видео / RTSP / SDP: crop, расчёт дистанции, OSD-оверлей. Главный инструмент полевых тестов.
- **`export_ncnn_1280.py`** — экспорт `.pt` → NCNN для edge-деплоя (Raspberry Pi 5 и др.).
- **`autolabel_sort.py`** — сортировка / авторазметка кадров для сборки датасета.
- **`download/`** — скачивалки датасетов с HuggingFace / Kaggle.

## Чего здесь НЕТ (намеренно)
- **Весов моделей** (`.pt`, NCNN) — нет в репо.
- **Датасетов** — нет в репо.

И то и другое выдаётся **по запросу** верифицированным исследователям и энтузиастам, работающим над defensive early-warning. Открой issue с описанием, кто ты и что строишь — запросы рассматриваются индивидуально.

## Подход и честные находки
- **Публичные датасеты дронов — в основном крупные планы в 640px.** Дальних целей (3–5px) там почти нет. Реальный рычаг — **свои телекадры с ручной разметкой дальних целей**, а не новые скачивания.
- **Дальность ограничена данными, а не ёмкостью модели или разрешением.** Меряем распределение размеров целей до того, как доверять датасету — иначе только усиливаем перекос в крупные планы.
- **Метрики val врут про дальность:** val, размеченный слабой учительской моделью, штрафует студента за детекцию дальних целей, которые учитель пропустил. Доверяй полевым тестам на реальном видео.
- Переход 640 → 1280 помогает (эффективный stride падает, дальняя цель получает ячейки сетки), но потолок — отсутствие дальних целей в обучающих данных.

## Стек
YOLOv8 (n / s) @ imgsz=1280, ultralytics, NCNN для edge. Python 3.13, OpenCV, PyTorch (CUDA). ESP32 для аппаратного алёрта (one-shot поочерёдная сигнализация по 4 лампам).

## Статус
Личное исследование, активная разработка. Не production. Жди шероховатостей — они зафиксированы в коммитах и заметках.

## Дисклеймер
Система defensive раннего предупреждения: **только детекция и оповещение**. Без целеуказания, без противодействия, без offensive применения. Для сценариев наблюдательного поста и гражданской защиты.
